# Quick Configuration Checker

## Use this to verify your setup before deploying

### ✅ Render Configuration Check

**Go to:** https://dashboard.render.com → Your Service → Settings

Verify these match:

```yaml
Name: spotter-django-api
Root Directory: packages/django-backend  # ⚠️ MUST BE EXACT
Environment: Python 3
Build Command: pip install -r requirements.txt && python manage.py collectstatic --no-input && python manage.py migrate
Start Command: gunicorn config.wsgi:application
```

### ✅ Render Environment Variables Check

**Go to:** https://dashboard.render.com → Your Service → Environment

```bash
SECRET_KEY=<auto-generated>
DEBUG=False
ALLOWED_HOSTS=<your-render-url>.onrender.com,<your-vercel-url>.vercel.app,localhost
FRONTEND_URL=https://<your-vercel-url>.vercel.app
PYTHON_VERSION=3.11.0
```

**Example:**
```bash
ALLOWED_HOSTS=spotter-django-api.onrender.com,eld-system-frontend.vercel.app,localhost
FRONTEND_URL=https://eld-system-frontend.vercel.app
```

### ✅ Vercel Configuration Check

**Go to:** https://vercel.com → Your Project → Settings → Environment Variables

```bash
VITE_API_BASE_URL=https://<your-render-url>.onrender.com/api
```

**Example:**
```bash
VITE_API_BASE_URL=https://spotter-django-api.onrender.com/api
```

## 🧪 Testing Checklist

### Test 1: Django Backend Health

Open in browser or use curl:

```bash
curl https://your-render-url.onrender.com/health
```

**Expected:**
```json
{"status": "OK", "service": "Spotter Django API", "version": "1.0.0"}
```

❌ **If 404:** Root Directory is wrong
❌ **If timeout:** Service isn't running
❌ **If 500:** Check Render logs for errors

### Test 2: Django API Root

```bash
curl https://your-render-url.onrender.com/
```

**Expected:**
```json
{
  "message": "Spotter ELD API",
  "version": "1.0.0",
  "endpoints": {
    "health": "/health",
    "api": "/api/",
    "eld_logs": "/api/eld-logs/",
    "route_planning": "/api/route",
    "admin": "/admin/"
  }
}
```

### Test 3: Django API Endpoint

```bash
curl https://your-render-url.onrender.com/api/eld-logs/list/
```

**Expected:**
```json
{
  "logs": [],
  "count": 0,
  "offset": 0,
  "limit": 100,
  "status": "success"
}
```

### Test 4: Frontend Loads

Open in browser:
```
https://your-vercel-url.vercel.app
```

**Check:**
- [ ] Page loads without errors
- [ ] No CORS errors in console (F12)
- [ ] Map displays
- [ ] Forms are interactive

### Test 5: Frontend → Backend Communication

1. Go to Trip Planning page
2. Enter locations and click "Plan Trip"
3. Check browser console (F12) for:
   - API request to Render URL
   - No CORS errors
   - Successful response

### Test 6: Create ELD Log

1. Fill in ELD log form
2. Click "Create ELD Log"
3. Should see success message
4. Go to Dashboard
5. Should see your log

## 🚨 Common Issues & Fixes

| Issue | Cause | Fix |
|-------|-------|-----|
| 404 on all endpoints | Wrong Root Directory | Set to `packages/django-backend` |
| CORS error | Wrong FRONTEND_URL | Match exact Vercel URL |
| 500 error | Missing dependency | Check Render logs, add to requirements.txt |
| Timeout | Service sleeping | Wait 30-60s for wake-up (free tier) |
| "Route not found" | Missing URL handler | Check urls.py has root and health endpoints |

## 📋 Pre-Deployment Checklist

Before deploying, verify:

### Backend (Django)
- [ ] `packages/django-backend/requirements.txt` exists
- [ ] `packages/django-backend/config/wsgi.py` exists
- [ ] `packages/django-backend/config/settings.py` has CORS config
- [ ] `packages/django-backend/config/urls.py` has root and health endpoints
- [ ] `packages/django-backend/manage.py` exists
- [ ] All migrations created: `python manage.py makemigrations`

### Frontend (React)
- [ ] `packages/Client/src/services/api.ts` configured
- [ ] API_BASE_URL uses environment variable
- [ ] Components use API service functions
- [ ] No hardcoded API URLs in components

### Git Repository
- [ ] All changes committed
- [ ] Pushed to GitHub
- [ ] Repository connected to Render
- [ ] Repository connected to Vercel

## 🔄 Deployment Steps

### Step 1: Deploy Django to Render

1. Create new Web Service
2. Connect GitHub repo
3. Set Root Directory: `packages/django-backend`
4. Add all 5 environment variables
5. Deploy (wait 3-5 minutes)
6. Test `/health` endpoint
7. Copy your Render URL

### Step 2: Configure Frontend on Vercel

1. Go to your Vercel project
2. Settings → Environment Variables
3. Add `VITE_API_BASE_URL` with your Render URL
4. Redeploy

### Step 3: Update ALLOWED_HOSTS on Render

1. Add your Vercel URL to ALLOWED_HOSTS
2. Format: `render-url,vercel-url,localhost`
3. Save and redeploy

### Step 4: Test Integration

1. Visit Vercel URL
2. Test all features
3. Check for errors in console
4. Verify data saves and loads

## 🎯 Success Indicators

Your deployment is successful when:

✅ Django health check returns 200 OK

✅ Can plan routes (map shows route)
✅ Can create ELD logs
✅ Can view logs on dashboard
✅ No CORS errors in browser console
✅ Logs persist after page refresh

## 📞 Getting Help

If stuck:

1. Check browser console for errors
2. Check Render logs for Python errors
3. Verify all URLs match exactly
4. Test API endpoints directly in browser
5. Review CORS configuration
6. Check environment variables are set

**Key files to review:**
- `packages/django-backend/config/settings.py` (CORS config)
- `packages/django-backend/config/urls.py` (URL routing)
- `packages/Client/src/services/api.ts` (API calls)
